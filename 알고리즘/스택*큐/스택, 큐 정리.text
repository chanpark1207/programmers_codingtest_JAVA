<스택>
원형통에 원형 블럭을 쌓는 느낌 위에서 부터 꺼낼수 있음
Stack<형> stack = new Stack<>();

stack.push(10); // 데이터 추가
stack.pop();  // 마지막 데이터 제거및 반환
stack.peek();  // 마지막데이터 확인 (제거는 하지 않음)
stack.isEmpty();  // 비어있는지 확인
stack.size();  // 데이터 갯수, 길이
stack.contains(10);  // 10이라는 데이터가 포함되어있는지 
stack.clear();  // 모든데이터 삭제 초기화
stack.get(인덱스번호);  // 해당인덱스번호의 데이터 값 가져오기

*빈스택에서 pop하면 EmptyStack Exception 발생

<큐>
줄서기나 양쪽이 뚫린 파이프 느낌 들어간순서대로 앞에서 부터 꺼내짐
LinkedList 나 ArrayDeque 사용 보통 후자 많이 사용
Queue<형> queue = new ArrayDeque<>();

queue.offer(10);
queue.add(10);  // 둘다 데이터 추가

queue.pull();  // 맨앞 데이터 제거 및 반환
queue.peek():  // 맨앞 데이터 확인(제거는 하지 않음)
queue.isEmpty();  // 비어있는지 확인 
queue.size();  // 데이터 갯수 확인, 길이
queue.contains(10);  // 10이라는 데이터가 포함되어있는지
queue.clear();  // 모든데이터 삭제 초기화

*빈 큐에서 pull하면 null 출력
